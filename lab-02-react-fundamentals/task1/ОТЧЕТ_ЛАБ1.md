# Отчёт по лабораторной работе №1 (React + Vite, JS)

## Как выполняли задание

### Общее

Проект создан на **Vite** с шаблоном **React**. Используются React 19, JSX. Все задания сделаны в одном файле `src/App.jsx`: компоненты и экспорт главного `App`.

---

### Задание 1. Разметка на Fragment (header / main / footer без обёртки div)

**Что сделано:**  
Компонент `FragmentLayout` возвращает разметку из трёх блоков — `<header>`, `<main>`, `<footer>` — **без общего wrapper-элемента** (без лишнего `<div>`). Для этого использован **React Fragment** — короткий синтаксис `<> ... </>`.

В итоге в DOM нет лишнего div, есть только header, main и footer. В header — заголовок «Fragment Layout», в main — поясняющий текст, в footer — копирайт.

---

### Задание 2. Список из массива через map и key

**Что сделано:**  
Задан массив объектов `items` с полями `id` и `name` (например: Apple, Banana, Cherry). Компонент `ItemList` рендерит список `<ul>`: элементы создаются через `items.map()`. У каждого `<li>` задан атрибут **`key={item.id}`**, чтобы React мог однозначно идентифицировать элементы при обновлениях (по требованиям React ключ должен быть уникальным в списке).

---

### Задание 3. Заголовок + список + итог (total) в одном Fragment

**Что сделано:**  
Компонент `CombinedFragmentList` объединяет в одном возвращаемом значении:
- заголовок `<h2>Fruits</h2>`;
- список из задания 2 — компонент `<ItemList />`;
- строку «Total: N items», где N — `items.length`.

Всё обёрнуто в один **Fragment** (`<> ... </>`), без лишнего div. Итог считается прямо в JSX: `{items.length}`.

---

### Сборка в приложение

В `App` по порядку рендерятся:
1. `FragmentLayout`;
2. горизонтальная черта `<hr />`;
3. `CombinedFragmentList`.

Точка входа — `main.jsx`, который монтирует `<App />` в `index.html` в элемент с `id="root"`. Запуск: `npm run dev`, сборка: `npm run build`.
