# student-portal

React + TypeScript + Vite app for Lab 06 (client-side routing with React Router).

See the [repository README](../README.md) for the feature overview and the
list of routes.

## Scripts

```bash
npm install
npm run dev        # development server
npm run build      # type-check and production build
npm run preview    # preview the production build
npm run lint       # run ESLint
```
