# perf-app

React + TypeScript + Vite app for Lab 09 (React performance optimization).

See the [repository README](../README.md) for a description of each component
and the techniques it shows.

## Scripts

```bash
npm install
npm run dev        # development server
npm run build      # type-check and production build
npm run preview    # preview the production build
npm run lint       # run ESLint
```
