# Lab 8.1 - Next.js Blog with SSG/ISR

This task is implemented in the same project using:

- `src/pages/index.tsx` (SSG + ISR home page)
- `src/pages/posts/[id].tsx` (dynamic SSG routes)
- `src/types/index.ts` (Post/Author interfaces)
- `src/lib/api.ts` (blog data functions)

Run:

```bash
npm install
npm run dev
```
